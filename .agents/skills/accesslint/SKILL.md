# AccessLint Accessibility Suite

Comprehensive web accessibility assessment and remediation workflows aligned with WCAG 2.2.

## Workflows & Associated Skills

- **`accessibility-audit`**: Whole-site or end-to-end flow evaluation following WCAG-EM methodology. Produces graded conformance reports.
- **`accessibility-scan`**: Automated accessibility inspection for a single page or component.
- **`accessibility-inspect`**: Hands-on inspection for keyboard navigation, focus management, reflow, and ARIA attributes.
- **`accessibility-fix`**: Baseline-edit-verify loop to remediate detected accessibility violations while preserving design intent.
- **`accessibility-diff`**: Regression checking against previous audits or staging/production branches.

Methodology reference is located in [`../shared/methodology.md`](../shared/methodology.md).
